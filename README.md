# 忍札戦記 Ver.1.0

月下の五番勝負を戦う、1人用デッキ構築カードバトル。HTML / CSS / JavaScript のみで動作します。タップ・マウス・キーボードに対応し、外部配信の画像・フォントやAPI、データベースは使いません。

## ダウンロードして遊ぶ（プログラミング不要）

1. GitHubのこのページ上部にある緑色の **Code** を押し、**Download ZIP** を選びます。
2. ダウンロードしたZIPを展開します。Windowsは右クリックして **すべて展開** → **展開**。MacはZIPをダブルクリックします。
3. 展開されたフォルダーの中の **遊ぶ.html** をダブルクリックします（表示設定によっては「遊ぶ」と表示されます）。
4. Chrome・Edge・Safariなどのブラウザにタイトルが表示されたら **いざ、出陣** を押します。

このファイルにはゲーム一式が入っているので、追加のアプリやサーバーは不要です。元のZIPを開いたままではなく、展開したフォルダーから起動してください。セーブは同じパソコン・同じブラウザで使います。ファイルの直接表示ではブラウザによってセーブが使えない場合があり、そのときは画面に警告します。

## 開発用の起動

Python 3 がある環境で、このリポジトリを作業ディレクトリにして実行します。

```sh
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開きます。Node.js がある場合は `npm start` も同じ動作です。依存パッケージのインストールは不要です。開発用の `index.html` はES Modulesを使うためHTTPサーバーで起動してください。直接開いて遊ぶ場合は `遊ぶ.html` を使います。

## 遊び方

「いざ、出陣」から開始。敵の予告を見ながら札をタップして使い、行動力がなくなったら「ターン終了」。手札は横にスクロールできます。勝利後は三択の札を一枚獲得して次の戦闘へ。5戦目の忍頭・黒月を倒せばクリアです。ヘッダーの「遊び方」はいつでも開けます。

操作が完了するたびにブラウザのLocalStorageへ自動保存します。タイトルの「続きから忍ぶ」で戦闘中・報酬選択・終了画面を復元できます。同一ブラウザ・同一オリジンのみで有効です。新規開始時はタイトルで既存セーブの上書きを確認します。保存が拒否されたときは画面に警告し、ゲーム自体は続行できます。不正なデータや非対応バージョンは読み込まず、新規開始できます。複数タブでの同時進行・セーブのクラウド同期は対象外です。

## 暫定ルールと処理順

目標プレイ時間は5〜10分。難易度は初回クリアを狙いやすい暫定値です。時間は操作速度によって変わります。

- 初期HP・最大HPは40。HPは0〜40、行動力は0〜10。通常のターン開始時は行動力を3に戻します。回復や追加行動力は上限を超えません。防御・毒・筋力・弱体は0未満になりません。
- 初期デッキは手裏剣5・煙玉4・兵糧丸1。戦闘開始時に全デッキをシャッフルして5枚引きます。以降も毎ターン5枚引き、山札不足時は捨て札をシャッフルして続けます。手札枚数上限はありません。山札も捨て札も空なら引ける分で止まります。
- 札は行動力を支払い、手札から取り除き、効果を記載順に解決してから捨て札になります。解決中の札自身をドローで引き直すことはありません。同名札の重複獲得は可能です。
- 攻撃は1ヒットごとに筋力を加算し、防御から先に引きます。残りがHPダメージです。HPは0で止まります。敵の弱体は攻撃1ヒットごとに0.75倍・小数点切り捨てで計算します。
- **ターン終了**：残り手札を捨てる → 敵の防御消失 → 敵の毒ダメージと毒1減少 → 勝敗確認 → 予告済みの敵行動 → 敵の弱体1減少・行動順更新 → 勝敗確認 → 自分の防御消失 → 自分の毒ダメージと毒1減少 → 勝敗確認 → 行動力3・5枚ドロー。
- 毒は防御を無視します。敵がこのターンに付与した毒も、直後のプレイヤーターン開始時に発動します。弱体2は敵の2行動に有効です。敵の予告攻撃値は弱体を反映します。
- プレイヤーHP0を最優先で敗北判定します。敵HP0で勝利（毒で倒せば敵行動なし）。通常勝利でHP8回復・重複しない3種類から1枚獲得。5戦目はそのままクリアで、追加報酬や回復はありません。
- 防御・毒・弱体・筋力・山札などの戦闘状態は次の戦闘開始時にリセット。HPと獲得したデッキは持ち越します。追加札は全13候補から等確率で提示します。
- 敵は固定順で登場し、各自の行動配列を先頭から繰り返します。乱数はシャッフルと報酬候補にのみ使います。

## 構成・バランス調整

- `js/cards.js`：15種類のカード定義、効果データ、初期デッキ、報酬候補
- `js/enemies.js`：5体のHP、台詞、行動配列、次の行動選択
- `js/engine.js`：DOMに依存しない戦闘・ドロー・勝敗・報酬処理。乱数関数を注入可能
- `js/storage.js`：セーブ・読込・スキーマ検証。キーは `ninsatsu-senki-v1`
- `js/ui.js`：画面遷移、イベント処理、描画、保存の呼出し
- `遊ぶ.html`：ダウンロード後に直接開ける、ゲーム一式をまとめたファイル
- `tools/build-offline.mjs`：`node tools/build-offline.mjs` で上記ファイルを再生成（ソースを変更したら実行）
- `style.css`：レスポンシブ表示、札の演出、動きを減らす設定への対応
- `tests/engine.test.js`：Node標準テストランナーによる自動テスト

効果は `[効果名, 数値]` の配列です。数値変更はカード・敵の定義で行えます。新しい効果の追加は `engine.js` の処理を拡張してください。

## テスト

Node.js 18以上（検証環境は24）で実行します。

```sh
npm test
```

ダメージ、防御、HP・行動力上限、ドローと再シャッフル、カード保存則、筋力・多段攻撃、毒・弱体と処理順、回復・解除、報酬、5戦通しの勝利、敗北、終了後の操作無効化、セーブ検証を確認します。

ブラウザでは390px・1280px幅で、遊び方、札使用、ターン終了、リロード後の復帰、ページの横はみ出し、コンソール例外を確認しています。実機の全機種保証や長期的なバランス調整は未実施です。

## 公開

`index.html`・`style.css`・`js/` を同じディレクトリ構成で静的ホスティングへ配置してください。ビルド処理やサーバー側プログラム、環境変数は不要です。JavaScriptが正しいMIMEタイプで配信される一般的なHTTP/HTTPSサーバーで動作します。サブディレクトリ配置にも対応します。

GitHub Pagesなら、このファイル一式をリポジトリにコミット・プッシュ後、Settings → Pages → Deploy from a branch で公開対象のブランチと `/ (root)` を指定できます。Webサイトとしての公開は別途設定が必要です。公開先を変更すると、オリジンが変わるためセーブは引き継がれません。
